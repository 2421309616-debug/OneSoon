# Home Page Overrides

**Project:** 万顺 OneSoon
**Page:** 用户端首页

## Layout

- 页面铺满窗口，手机单列；平板和桌面将下方推荐卡片排为两列或三列，上车卡与小应用始终占满一行。
- 高度不超过 500px 时使用自然滚动布局；更高窗口保留拖动面板。
- 上：地图预留区，约 40vh，`#E8EAED`。
- 左上角字标：万顺（`#D0121A`）+ OneSoon。
- 白卡片：上车点「请选择上车点」、目的地输入框（红色描边）、小应用宫格。
- 底栏：首页、我的。首页为选中。

## Not on this page

优惠、待支付、预约、帮人叫车、接送机、司机位置和路线导航。
